# EZ-Reader

浏览器阅读扩展：将网页正文或所选区域转换为分级标题和宽松段落的阅读视图。阅读与排版本地完成，另支持免费或 DeepSeek 全文翻译、划词翻译及生词学习；不使用远程字体，PDF 解析组件随扩展打包。文档阅读方式见 [PDF 使用说明](documents.md)。

## 构建与安装

使用 Node.js 24，无需安装 npm 依赖：

```powershell
node tools/build.js
```

在 Edge 或 Chrome 的扩展管理页开启开发者模式，点击“加载解压缩的扩展”，选择本项目的 `dist/extension` 目录。更新代码后重新构建，在扩展管理页点击“重新加载”，再刷新正在阅读的网页。

点击扩展图标或按 `Alt+Shift+E`，弹窗提供“打开工具栏”主按钮和“打开 PDF”入口。工具栏默认显示在原网页上，点击“简洁阅读”才提取正文，不会自动全文翻译。

“简洁阅读”与“选择区域”合并为左右两段式按钮；进入阅读后，左侧显示为“原网页”，右侧选区置灰。字体、缩放和大纲仅在简洁阅读下可用，相关按钮与快捷键同样受此限制。首字母大写、设置、翻译及关闭工具栏在两种视图下均可使用。

按钮组末端的“移到底部 / 移到顶部”用于在窗口顶部与底部之间切换停靠位置。停靠到窗口底部后，分隔线与阴影翻转至上侧，原网页顶部不再被工具栏遮挡，阅读视图的正文也完整显示在工具栏上方。停靠边属于工具栏自身设置，对所有网站生效，并在换页、刷新和重启浏览器后保持；工具栏按钮的文字与按下状态随当前停靠边同步变化。

工具栏在当前浏览器窗口的普通网页中常驻：链接跳转、刷新、新标签页和单页应用换页后会自动显示，其他窗口不受影响。新页面仍显示原网页，不自动提取或翻译；标签页跨窗口移动时采用目标窗口的状态。点击主工具栏最右侧灰色 × 只隐藏当前页主栏，翻译工具栏、当前阅读视图和划词仍保留。已隐藏的主栏不会因为切换标签页重新出现；可点击翻译栏的「阅读工具」或从扩展面板重新打开。翻译工具栏的 × 仅隐藏翻译栏。关闭浏览器窗口、重启浏览器或重新加载扩展后需要重新开启。

“设置”在两种视图中都打开右侧抽屉。划词开关位于翻译工具栏。原网页的设置抽屉可调整划词后自动翻译、翻译服务、原文与目标语言、DeepSeek 模型、界面配色、首字母大写和按网站记住显示设置；“API 密钥与生词本”打开扩展配置页。排版、段落与词语学习设置仅在简洁阅读中显示。通用翻译偏好会同步到已打开的划词浮层和全文工具；翻译设置全站共用，显示设置可按站点保存。

原网页首字母大写仅调整文字样式，不改写文字、不插入包装节点，保留链接与事件目标；代码、编辑区和表单控件保持原样，动态加入的内容也会生效。关闭功能、进入简洁阅读或选择区域时还原样式，返回原网页或取消选区后恢复。划词仍发送原始词形并复用原有缓存。

按 `Esc` 优先收起划词浮层、设置面板或选区；阅读视图中再按 `Esc` 返回原网页并保留工具栏。点击“简洁阅读”可返回之前的阅读位置。

重新选择区域时，先切换到“原网页”，再点击“选择区域”。即使自动提取没有找到正文，也可以手动选择短段落；按 `Esc` 或右键取消后继续显示原网页工具栏。原网页节点和事件处理器始终保留在原位。

## 缩放行为

普通分段不添加项目符号；实际列表保留小点或有序编号。原网页中无标记的列表布局按普通段落显示，单个列表项中的换行不会生成额外分点。

- 默认设计列宽为 `44rem`（页面根字号为 16px 时对应 704px）。“适配”按钮按窗口可用宽度与设计列宽之比缩放，宽屏放大、窄屏缩小，正文列在保留内边距后铺满阅读窗口。
- 适配倍率范围为 60%–250%，例如可用宽度 1265px 对应约 180%。窄屏达到最小倍率后正文继续换行；超宽窗口达到最大倍率后保留居中留白。
- 手动缩放支持 60%–250%，工具栏的加减按钮每次调整 10 个百分点。
- 阅读正文只应用一次缩放；工具栏显示实际倍率。切换主题或字体时保持自动适配结果。

## 划词翻译与 DeepSeek 配置

1. 进入阅读视图并选中文字，点击浮层里的“免费翻译”或“DeepSeek”。一次最多 2000 个字符，按 Esc 收起译文。浮层与翻译设置均可勾选“自动翻译”：选区稳定约 450ms 后自动请求当前所选服务，拖选途中、换选区和关闭浮层会取消尚未发出的请求。默认关闭，不同时请求另一种翻译 API。
2. 两种视图的「翻译工具」栏均可调整划词开关和全文／划词目标语言；「设置」中可调整自动翻译、服务和原文语言；“API 密钥与生词本”打开配置页。默认自动识别原文、译为简体中文。
3. MyMemory 免费翻译无需密钥，仅发送选中文字；按接口 UTF-8 限制分块，并显示额度、连接与限流错误。[MyMemory API 文档](https://mymemory.translated.net/doc/spec.php)
4. DeepSeek 在配置页填写自己的 API Key 并点击“保存翻译设置”。密钥保存在扩展后台所属的本机 IndexedDB，不放入网页内容脚本可读的共享设置存储，不回传阅读页面；费用取决于你的 DeepSeek 账户，未配置时不会发起请求。默认 deepseek-flash，使用非思考模式。[DeepSeek API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)

首次使用 DeepSeek（手动点击或已开启预加载）时，后台发送当前阅读内容的节选（最多 12000 字符，长文取开头、中部、结尾）和标题，提取领域、语气与最多 12 个术语。后续翻译请求只使用简短摘要、相邻段落（最多 1500 字符）及当前选文；不累积历史译文，不重复发送全文。只输出译文，网页里的指令按待译数据处理，普通段落不加项目符号。

语境按标签页、文档、完整页面地址和阅读区域隔离；页面地址（包括单页应用路由）改变、重新选区、关闭阅读或修改翻译语言、模型、密钥会清除旧语境。最多保留 16 个活跃语境、每个语境 48 个结果缓存，闲置 30 分钟失效。简短摘要保存在浏览器会话存储，供服务工作线程重启后恢复；浏览器重启后清空。配置页可以主动清除语境和删除密钥。切换预加载、讲解、卡片、学习水平等偏好时复用已有文章摘要，词语讲解按英语水平单独缓存。

提示词见 `src/translation/prompts.js`，后台与缓存逻辑见 `src/translation/service.js`。免费接口已用公开示例实测；自动化中的远端响应使用拦截模拟，不发送测试文章或消耗真实 DeepSeek 额度。

## 输入文本翻译

翻译工具栏的「输入文字」打开可拖动浮窗，在原网页和简洁阅读中都可用。它不依赖页面选区，关闭划词翻译后仍可手动翻译。

1. 点击主工具栏「翻译工具」，再点击「输入文字」。
2. 选择翻译服务和输入翻译的目标语言；这里的目标语言独立保存，不改变全文和划词目标语言。
3. 在「要翻译的文字」中输入或粘贴内容，一次最多 2000 个字符。
4. 按需填写「翻译风格提示词」，例如「口语化一点，保留专业术语的英文原词」。
5. 点击「翻译工具」，或在原文输入框内按 `Ctrl + Enter`（macOS 为 `Cmd + Enter`）。
6. 翻译完成后，点击「复制译文」。

翻译风格最多 500 字符，只对 DeepSeek 生效，与划词及全文翻译共用。留空时恢复默认风格。编辑后自动保存，点击翻译会先等待最新设置保存完成；保存失败时保留输入并提示重试。翻译期间无法修改输入、设置或清空结果。

如需填写 DeepSeek API Key 或指定原文语言，点击浮窗中的「翻译设置」。免费翻译无法识别短文本语言时，可在设置页手动指定。

拖动标题栏可移动浮窗。窗口高度不足时，浮窗内可以滚动；按 `Esc` 或点击右上角的关闭按钮可收起浮窗。复制失败时，可以手动选中译文复制。

输入文本翻译只发送输入文字，不读取网页正文进行语境分析。修改风格后，已有译文及语境缓存失效；划词和全文翻译会在下次请求时重新分析文章语境。

## 全文翻译、双语对照与批注卡片

打开工具栏后，在原网页或简洁阅读中点击“翻译工具”。在服务下拉框中选择“免费翻译”或“DeepSeek”，在「译为」选框选择全文和划词共用的目标语言，再点击“全文翻译”。免费翻译使用 MyMemory，无需密钥；DeepSeek 需要在翻译设置中填写 API Key。全文翻译会发送当前视图文字，长文分段串行处理，支持停止；“全文翻译”和“显示原文”由同一按钮切换，重试复用已完成结果，不会加载时自动翻译整页。只请求所选服务，不自动切换到另一种 API。

- 点击工具栏“原网页”后，在同一套阅读器工具中翻译网站页面，直接替换可读文字，保留链接、强调、控件和事件监听；代码、编辑框、隐藏内容、禁止翻译的区域跳过。“显示原文”恢复原文字，不覆盖网站在此期间自行更新的节点。返回阅读或关闭阅读器时恢复网站页面，不留下独立翻译浮条。
- 原网页全文翻译优先处理占据页面主体的大块正文，再处理导航、侧栏等其余文字。根据区域面积、正文量和 main/article 等标记识别主体，没有语义标记的布局也会参与识别；区域内部保持原文顺序。免费翻译和 DeepSeek 使用相同顺序，继续翻译仍复用已完成结果。
- 划词仅对当前可见的原文生效，跟随统一的划词翻译设置，无单独的“原网页划词”开关。译文及混合选区不弹窗、不预加载、不反向翻译；双语对照只在原文一侧划词。“原网页”模式的浮层只提供翻译，不显示阅读器生词卡；按 Esc 优先收起浮层。
- 阅读器默认双语对照，可切换为仅译文。两种视图复用相同段落的结果，修改字体或切换双语不重新请求翻译；页面地址、目标语言或模型改变时丢弃旧结果。
- 阅读器里的“划词生词卡”控制批注生成；学习英语时在双语对照的原文中划选。英语水平 A1–C2 与翻译设置同步；DeepSeek 单独选词按所选水平讲解，选中长段按该水平挑选最多 6 个值得学习的词。改变水平清除旧批注；之后只重新生成该水平的讲解，不重译正文。免费模式仍使用词典扩展。
- 卡片显示在正文两侧，窄屏显示最近一张底部卡片。批注上可单独加入生词本或导出 Anki。生成不等于保存，自动加入仍是独立选项，默认关闭。

全文翻译只要求普通译文，不再请求、存储或校验词语对应关系。为保留链接和强调，按原有格式边界分段；免费接口每次发送不超过 480 个 UTF-8 字节。MyMemory 匿名免费额度目前为每天 5000 字符，长文可能达到限制；届时显示错误并保留已完成内容，不悄悄调用付费服务。[MyMemory 额度说明](https://mymemory.translated.net/doc/usagelimits.php)

全文缓存按翻译服务分别保存，切回某服务会复用其结果；跨视图、双语切换和重复文本共享缓存。失败重试只请求尚未完成的文本，免费段落中已成功的小块也会复用。缓存位于当前网页内存，刷新会清空；后台缓存受 30 分钟会话有效期及容量约束。

## 单词卡与 Anki 生词本

讲解、卡片和保存是三个独立步骤：浮层可分别勾选“讲解”“生成卡片”，设置页另外提供“将生成的卡片自动加入生词本”（默认关闭）。只看讲解时不生成导出卡片；只生成卡片时，单词直接使用词语与译文，不请求额外讲解；二者同时关闭就只显示译文。生成卡片不会自动保存，只有手动点击加入或另外开启自动加入才写入本机生词本。

开启讲解后，免费模式查询 [Free Dictionary API](https://dictionaryapi.dev/)，不可用时自动尝试 [维基词典](https://en.wiktionary.org/wiki/Wiktionary:Main_Page)；目前支持英文词语，保留可用的音标、词性与词典来源，释义和例句由 MyMemory 转译。词典未收录或离线时，仍可生成、保存已有译文的基础卡片。多义词按相邻段落匹配一条词典释义，可点击来源核对。

DeepSeek 讲解复用当前阅读语境，用独立提示词生成一句通俗解释、一个搭配或用法、一个短例句，标明“AI 生成”。扩展内容不会混进纯翻译提示词，也不会进入后续聊天历史。

选用 DeepSeek 后，可设置 A1–C2 英语水平（默认 B1）。段落翻译后会按水平挑选最多 6 个本段词语；浮层的“本篇生词”可从当前阅读内容节选中挑词，无需选中全文，长文仍只发送最多 12000 字符的节选。低水平侧重基础表达，高水平侧重专业词和细微用法；难度由 AI 估计，不保证严格等级。只生成卡片时，长文挑词仅返回词语与译文，不附加讲解。所有结果必须对应原文出现的词语，原句由本机从选文或节选中提取，结果可为空。

- 点击卡片的“导出 Anki”下载当前卡片；点击“加入生词本”保存在本机，再从翻译设置中的“生词本”批量导出。
- 在 Anki 中选择“文件 → 导入”，打开 `ez-reader-anki.txt`，笔记类型选 Basic，两列分别映射正面与背面。文件包含分隔符、HTML 和 EZReader 标签设置；背面保留译文、讲解、原句与来源。[Anki 官方导入说明](https://docs.ankiweb.net/importing/text-files.html)
- “通用 TSV”按一行一张、制表符分隔词语和释义，可复制到 Quizlet 导入框或用于其他支持 TSV 的软件。
- 生词本最多 500 张，可搜索、逐张移除；同一词语和语言组合再次保存会更新卡片。导出不清空生词本，扩展不会自动上传卡片或连接 Anki 账户。

词典查询只发送当前词语；转译释义会额外使用免费翻译额度，AI 讲解或长文挑词会额外调用一次 DeepSeek。只生成单词基础卡片不增加 API 调用。关闭讲解和卡片后不发起词典/挑词请求；免费模式不会为长文偷偷调用 DeepSeek。词典数据保留来源和许可，导出中的外部文字均经过 HTML 转义。

## 验证

```powershell
node tools/build.js
node tools/smoke-bundle.js
node tools/run-tests.js
node tools/browser-test.js
```

也可运行 `npm.cmd test`（单元测试）或 `npm.cmd run verify`（完整验证）。

浏览器测试使用真实 headless Edge 和项目内独立配置目录，覆盖 10 个本地 fixture，包括全文翻译、划词与列表、长文、中文、富文本、延迟加载页面和存在页面样式干扰的交互测试。工具栏测试验证单按钮弹窗、视图限制、换页与刷新、同窗口新标签页、窗口隔离、跨窗口移动和关闭状态。测试检查首次打开的倍率、窄屏适配、实际文字缩放、设置更新、原文不变及退出还原，并用真实鼠标和键盘事件验证划词翻译、设置抽屉、原文切换、直接选区、重新选区及取消。全文测试验证免费与 DeepSeek 纯文本翻译、跨视图/服务缓存、额度失败重试、英语水平批注和停止后继续。可用 `EZR_BROWSER` 指定其他 Chromium 可执行文件，或用 `--only=toolbar`、`--only=full-translation`、`--only=translation`、`--only=paper`、`--only=interaction` 单独验证。受限执行环境可能需要允许浏览器创建子进程和 IPC 管道。

生成打开状态的阅读器截图：

```powershell
node tools/screenshots.js paper.html rich.html
```

截图保存到 `test-artifacts/shots/`，其中 `*-settings*.png` 展示设置抽屉的浅色、深色和窄窗口效果。`tools/browser-test.js` 默认保存的是退出后的原网页截图；`tools/diagnose-size.js` 用于打印首次打开时的字号、设计宽度和缩放数据。

手动浏览示例页面：

```powershell
node tools/serve.js
```

打开 `http://localhost:8788/`。模块间接口约定见 `CONTRACTS.md`。
