# PDF 与网页预览

## 浏览器已经打开 PDF

点击扩展图标，再点击「打开 PDF 工具栏」（也可使用「打开 PDF」）。扩展会在新标签页显示保留原排版的 PDF，并打开工具栏。此入口使用扩展自己的 PDF 视图，不往浏览器内置查看器里注入工具栏。

- 点击主工具栏「翻译工具」，在第二栏开启「划词翻译」。选中文字后，浮窗自动出现；点击所需服务开始翻译。浮窗中的「自动翻译」另行控制是否自动发送选中文字。
- 点击「全文翻译」，译文直接替换 PDF 原页上的文字，保留各文本框的位置。译文超过文本框时先缩小行距，再缩小字号，保留完整文字。点击「显示原文」恢复原页文字；两个操作均不切换当前阅读模式，已完成结果留在缓存中。
- 翻译工具栏的「译为」由全文和划词翻译共用，包括浏览器右键选文翻译。点击「输入文字」可翻译输入或粘贴的内容，该窗口的目标语言独立保存，也不受划词开关限制。
- PDF 页码、「适应宽度」和「适应高度」调整原 PDF。「适应高度」按工具栏之外的可用空间显示当前页；翻页、调整窗口大小或工具栏高度后重新适配。较宽页面可横向滚动，也可切回「适应宽度」。字体、首字母大写等阅读排版设置在简洁阅读视图中使用。

两栏的按钮从同一位置开始，停靠位置各自独立。右侧固定为另一工具栏入口、停靠图标和灰色 ×，停靠图标紧挨 × 左侧，与 × 一样不带边框；「翻译工具」与「阅读工具」始终显示，点击可打开另一栏。横线加箭头图标随位置切换移动方向，PDF 上下留白跟随两栏实际占用高度调整。× 只隐藏对应工具栏，翻译、划词和当前阅读视图仍保留；PDF 窗口也可点击「工具栏」恢复主栏。

翻译栏记住当前浏览器窗口内最近一次打开或关闭的选择。网页换页、刷新和同窗口新标签页会沿用该选择，PDF 换文件及重新打开阅读页也会保留。已打开的其他标签页不会被强制切换；恢复工具栏不会自动开始全文翻译。关闭整个窗口的网页工具栏后，换页仍保持关闭。

## 重试全文翻译失败项

某个片段翻译失败后，全文翻译继续处理其他片段，并在工具栏显示失败数量。点击「重试失败项」重新翻译这些片段，无需先切回原文。已成功的片段继续显示，并复用缓存。

PDF 阅读页显示「重试失败页」及未完成的页码。点击后，只重试这些页面中的未成功片段；已有译文不重复请求。若译文已经生成但页面显示失败，重试会直接用已有译文重新绘制，也会处理当前视口外的失败页。某页仍然失败时，会保留失败记录并继续处理其他页面。

没有文字层的扫描页需要先做 OCR，重复点击重试无法补出文字层。

重试期间可点击「停止」。更改目标语言、原文语言、模型或翻译风格后，需要重新开始全文翻译。此入口同时适用于网页、简洁阅读和扩展的 PDF 阅读页。

## 调整工具字体

在独立设置页或工具栏「设置」中的「显示」区域，调整「工具字体缩放」（75%–175%）。阅读栏、翻译栏和 PDF 编辑栏共用这一设置，按钮高度与工具栏留白随字号变化。此设置对所有网站生效，不改变正文或 PDF 译文字号。

## 批量调整 PDF 译文字号与对齐

PDF 打开后即可使用「批量编辑」。首次进入时提取文字并显示可选文本框，无需先翻译。

1. 点击「批量编辑」。
2. 点击一个译文文本框，或拖出矩形选择多个文本框。
3. 输入字号，选中文字立即刷新，无需点击应用。也可按住「拖动调字号」，向上拖动增大、向下拖动缩小；方向键微调，Shift 加速。
4. 在「水平」中选择左对齐、居中或右对齐，在「垂直」中选择上对齐、居中或下对齐。
5. 编辑完成后退出批量编辑。

字号以 PDF 点数计，页面缩放不改变设置值。译文按框宽重新换行，行间距随字号与字形高度自动调整。手动放大导致文字超出框时会提示，全文仍保留。

可将选中的文本框恢复为自动字号。多选框的字号或对齐不同时，控件显示混合状态。切换原文和译文、缩放或翻页会保留当前文档的字号与对齐，打开另一个文件会清除设置。导出 PDF 沿用调整后的字号、换行和对齐。

## 保留公式或其他区域的原文

1. 点击「批量编辑」，拖动框选公式所在的文本框；也可点击单选，配合 Ctrl / Shift 增减选择。
2. 点击「标记为原文」。选框变为棕色轮廓，选中或悬停时显示「原文」。公式可能分成主体、上下标等多个框，请把需要保留的部分一起框选。
3. 继续全文翻译。标记的文本框不再请求翻译，直接保留 PDF 的原始绘制，包括字形、上下标和位置；字号、对齐和恢复自动字号都跳过这些框。
4. 需要恢复翻译时，选中标记框并点击「取消原文标记」。已有缓存会立即恢复原译文及字号；没有缓存的框保持原文，在下次全文翻译或失败重试时处理。

翻译进行中也可标记：尚未发送的片段会跳过，已发送请求的迟到结果不会覆盖标记区域。失败片段标记后退出重试队列，取消标记后可重新重试。切换原文／译文、缩放、翻页和导出均保留标记；重新打开文件后清除。标记按提取出的完整文本框生效，不修改 PDF 源文件；图片与矢量公式原本就不会送去翻译。

## 导出译文 PDF

1. 翻译后点击 PDF 控制栏的「导出 PDF」。
2. 等待所有页面生成完毕，在新打开的预览中点击「打印 / 保存为 PDF」。
3. 在浏览器打印窗口选择「另存为 PDF」并保存。

导出沿用屏幕上的文本框排版、换行和字号，保留每页尺寸。译文以可选择文字输出；原页图形和未翻译内容作为页面图像输出，不保留原 PDF 的矢量图形、表单或链接。若翻译尚未完成，预览会标明未翻译文本框数量，并保留这些位置的原文。导出期间切换文件会取消导出。导出的页面在后台逐页生成，预览窗口获得焦点后无需切回 PDF 窗口，生成也会继续完成。

## Canvas 网页中的 PDF 预览

1. 在扩展面板点击「打开工具栏」。
2. 点击主工具栏「翻译工具」，开启「划词翻译」。
3. 在 PDF 控件中选择文字，浮窗读取实际选中文字。

可注入脚本的框架分别读取自己的选区，包含可访问的跨域框架。普通文本框也支持，密码框除外。插件不依赖正文提取器识别选区。如果控件不开放选区或浏览器禁止注入，自动浮窗无法显示。

这时可以使用浏览器右键菜单「用 EZ-Reader 翻译所选文本」，由浏览器传入选中文字；也可点击扩展的「打开 PDF」，在扩展 PDF 窗口中阅读。页面有多个候选文件时，先选择目标 PDF。

Canvas 登录态、下载权限、跨站 Cookie 或临时地址可能限制文件读取。若提示无法读取链接，从原预览点击 Download，然后在 PDF 窗口点击「打开文件」。文件在本机解析，无需上传给在线转换服务。

## 支持范围

- 支持 PDF，包括 PPT、Word 等文件导出的带文字层 PDF；不直接打开 PPT / PPTX 源文件。
- 按文字坐标合并相邻行，提取独立文本框、短标题、分栏文字和旋转文字，不使用网页正文长度阈值。PDF 通常不包含原始文本框边界，因此按字形占用范围估算文本框，译文可能比源文件字号小。
- 原页图形保留，译文使用系统字体，保留检测到的文字颜色和粗体。译文支持选择和复制。
- 扫描件可以阅读图像，但自动选文和全文翻译需要文字层；尚未提供 OCR。
- 文件最大 50 MB，最多 1000 页。全文提取最多 200 万文字字符；超限时提示拆分。
- 加密 PDF 需要先解除密码；本地文件网址需要扩展的文件访问权限，文件选择器无需该权限。

仅打开文件不发送翻译请求。选择翻译服务或开启浮窗中的「自动翻译」后，会发送相应文字；全文翻译由用户明确启动。
